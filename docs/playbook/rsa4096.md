## 2. Modular exponentiation encoding (e = 65537)

**Square-and-multiply, left-to-right, fully unrolled at synthesis time. NOT Montgomery.** No Montgomery form, no `R`, no REDC anywhere in the corpus.

`ModExp.lean:39-43,200-242`:
```lean
def eBits (e : ℕ) : List Bool := (Nat.bits e).reverse       -- MSB-first
def ofBits (bs : List Bool) : ℕ := bs.foldl (fun a b => 2 * a + (if b then 1 else 0)) 0
def modExpCount (e : ℕ) : ℕ := match eBits e with
  | [] => 0
  | _ :: tail => tail.length + tail.count true
def modExpLoop (P) (base n) : List Bool → Var (BigInt m) → Circuit …
  | [], acc => pure acc
  | bit :: rest, acc => do
      let sq ← subcircuit (MulMod.circuit P) { a := acc, b := acc, modulus := n }
      let acc' ← if bit then subcircuit (MulMod.circuit P) { a := sq, b := base, modulus := n }
                 else pure sq
      modExpLoop P base n rest acc'
def main (P) (input) := match eBits P.e with
  | [] => pure (Vector.ofFn fun k => if k.val = 0 then 1 else 0)   -- constant one, e = 0
  | _ :: tail => modExpLoop P.bigIntParams base n tail base        -- SEED with base (skip leading 1 bit)
```
Optimization: the leading bit is always `1` (`eBits_head_true`, `ModExp.lean:114`), so the accumulator is seeded with `base` rather than `1`, saving two wasted `MulMod`s (`1·1` and `1·base`).

For `e = 65537 = 2^16+1`: `eBits 65537 = true :: (List.replicate 15 false ++ [true])` (`MainTheorems.lean:153-154`, `by decide`). tail length 16, tail `count true = 1` ⇒ **`modExpCount 65537 = 17` `MulMod` subcircuits** (16 squarings + 1 multiply).

`mulModLen` (per-`MulMod` allocation, `ModExp.lean:206-208`):
```lean
def mulModLen (B W : ℕ) : ℕ :=
  m + m + m * B + m * B + (m * m) + (m * m) + ((2 * m - 1) * W + (2 * m - 1)) + (m + m * B + m)
```
At m=34,B=121,W=129 ⇒ **23500**; 17 · 23500 = **399500** allocations from `ModExp`.

### 2.1 Witness trick for modular reduction (`MulMod.lean:169-203`)

Exactly the "witness quotient + range-check remainder" pattern:
```lean
def main (P) (input) := do
  let q ← ProvableType.witness (α := BigInt m) fun env =>
    let prod := evalValue P.B env a * evalValue P.B env b
    let qval : ℕ := prod / evalValue P.B env n
    Vector.ofFn fun k : Fin m => ((qval / 2 ^ (P.B * k.val) % 2 ^ P.B : ℕ) : F p)
  let r ← ProvableType.witness (α := BigInt m) fun env => …(prod % …)…
  Normalize.circuit P q                      -- range-check q to m·B bits
  Normalize.circuit P r                      -- range-check r to m·B bits
  let Pc  ← witnessedMul a b                 -- affine convolution coeffs of a·b
  let Sqn ← witnessedMul q n                 -- affine convolution coeffs of q·n
  let S := Vector.mapFinRange (2 * m - 1) fun k =>
    if h : k.val < m then Sqn[k.val] + r[k.val]'h else Sqn[k.val]
  EqViaCarries.circuit P { lhs := Pc, rhs := S }   -- certify a·b = q·n + r over ℕ
  LessThan.circuit P { lhs := r, rhs := n }        -- certify r < n
  return r
```
Closing lemma: `MulMod.remainder_eq` (`MulModTheorems.lean:63-65`)
```lean
lemma remainder_eq {a b q n r : ℕ} (heq : a * b = q * n + r) (hr : r < n) : r = a * b % n := by
  rw [heq, Nat.add_comm, Nat.add_mul_mod_self_right, Nat.mod_eq_of_lt hr]
```

**R1CS-cleanliness trick — `witnessedMul`** (`MulMod.lean:58-72`): instead of feeding `EqViaCarries` the rank-≥2 schoolbook convolution `bigIntMulNoReduce a b` (coefficient = Σ a[i]·b[k−i]), each product `a[i]·b[j]` is witnessed as a fresh cell `pp[i*m+j]` with a single rank-1 row `a[i]*b[j] - pp[t] = 0`, and the coefficient vector returned is `bigIntMulVars pp` (`Theorems.lean:316-330`) — a *linear form over fresh cells*, hence affine. This is the key to `isR1CS`. Certified by `affineW_bigIntMulVars` (`Cost.lean:452`) and `isR1CSRow_mul_sub` (`Cost.lean:438`).

Eval bridge back to schoolbook: `map_eval_bigIntMulVars_eq` (`Theorems.lean:385`), `MulMod.witnessedMul_map_eval` (`MulModTheorems.lean:197`), `MulMod.witnessedMul_eval_bridge` (`MulMod.lean:106`).

### 2.2 Carry chains

**`EqViaCarries`** (`EqViaCarries.lean:64-93`) — signed carry with a constant offset so all values stay in ℕ:
```lean
carryOffset (B : ℕ) : ℕ := (m + 1) * 2 ^ (B + 1)                    -- Theorems.lean:740
-- witness: OFF + (Σ_{j≤k} P[j]2^{Bj} − Σ_{j≤k} S[j]2^{Bj}) / 2^{B(k+1)}
-- constraint k: Pc[k] + carryIn − Sc[k] − (carry[k] − OFF)·2^B = 0,  carryIn = 0 at k=0 else carry[k−1] − OFF
-- final:       carry[2m−2] − OFF = 0
-- each carry range-checked to W bits via Gadgets.ToBits.rangeCheck P.W P.hW
```
**`LessThan`** (`LessThan.lean:58-98`) — borrow chain via `a + d + 1 = b`:
```lean
-- witness d = b − 1 − a (limbs), Normalize d, witness m boolean carries
-- constraint k: a[k] + d[k] + carryIn + [k=0] − b[k] − carry[k]·2^B = 0
-- final: carry[m−1] = 0
```
The `+1` is folded into limb 0's constant so every row stays degree ≤ 1.

## 3. PKCS#1 v1.5 padding + digest embedding

**Padding is enforced by construction, not by assertion**: the EM frame bits are literal `Expression.const` values spliced around the witnessed digest bits.

`Bytes.lean:101-134`:
```lean
def derPrefix : Vector ℕ 19 :=
  #v[0x30, 0x31, 0x30, 0x0d, 0x06, 0x09, 0x60, 0x86, 0x48, 0x01,
     0x65, 0x03, 0x04, 0x02, 0x01, 0x05, 0x00, 0x04, 0x20]

def emByteConst (j : ℕ) : ℕ :=
  if j = 0 then 0x00 else if j = 1 then 0x01
  else if 2 ≤ j ∧ j ≤ 459 then 0xff
  else if j = 460 then 0x00
  else if 461 ≤ j ∧ j ≤ 479 then (if h : j - 461 < 19 then derPrefix[j - 461] else 0)
  else 0

def emConstBit (p : ℕ) : F circomPrime :=
  if p < 256 then 0 else ((emByteConst (511 - p / 8) / 2 ^ (p % 8) % 2 : ℕ) : F circomPrime)

def emBits (digBits : Vector (Expression (F circomPrime)) 256) : Vector _ totalBits :=
  Vector.ofFn fun p : Fin totalBits =>
    if h : p.val < 256 then digBits[p.val]'h else (Expression.const (emConstBit p.val))
```

- **why hand-written (verbatim comment, `Main.lean:56-62`)**: *"The larger per-`MulMod` length (now carrying the two `m*m` product matrices) pushes the whole circuit's offset past the kernel's reduction-stack limit, so the automated tactic (which forces a fully-reduced offset proof) hits `(kernel) deep recursion`."*

## 14. Cross-cutting engineering rules extracted (playbook-ready)

1. **Never let `circuit_norm` touch the goal when a deeply-recursive subcircuit is present.** Simplify hypotheses only (`… at h_holds` / `… at h_env`); discharge goal-side channel obligations by `Or.inl rfl`.
2. **Expose heavy children through `rfl` `have`s**, never through `simp only [Child.circuit]`: `have hMEass : (C).Assumptions = … := rfl`, `have hML : ∀ x, (C).localLength x = … := fun _ => rfl`, `have hMEg : (C).channelsWithGuarantees = [] := rfl`.
3. **Prove generic circuit-abstract `rfl` lemmas and instantiate at the heavy child** (`subcircuit_output_eq`, `subcircuit_localLength_eq`).
4. **Register a shallow `varFromOffset` closed form for recursive outputs with `@[circuit_norm]`.**
5. **Keep exponents / lengths symbolic**: fold `publicExponent`, `set bits := … * 8`, `i2osp` stated at symbolic `len`, `rw [show (1:ℕ)*4088 = 4088 from rfl]`.
6. **Destructure the parameter bundle before `circuit_proof_start`**: `obtain ⟨B, W, hB, hW, hB1, hWB, hWp, hp⟩ := P`.
7. **Prove in ℕ, lift to F by `congrArg Nat.cast` + `push_cast` + `ring`**; keep per-limb/per-index `_lift` lemmas (`per_limb_lift`, `per_index_lift`) with explicit no-wraparound bounds.
8. **`set` + `clear_value` before `omega`** so truncated ℕ subtraction is handled on opaque atoms.
9. **Isolate arithmetic into separate top-level lemmas for heartbeat budget** (`mulMod_*_core`, `witnessedMul_*`) — stated verbatim as the reason in three docstrings.
10. **Use `exact ⟨core.1, core.2.1, …⟩` rather than `obtain` when the projected term is huge** (avoids eager `whnf`).
11. **Witness products to keep R1CS rank 1**: any rank-≥2 sum-of-products fed to a downstream gadget should first be witnessed cell-by-cell.
12. **Duplicate the cost hierarchy for R1CS**, and add an `Affine*` output lemma per subcircuit so `bind_out` can thread it.
13. **Factor bulk constraints into a `FormalAssertion` (`ByteBlock`)** when the parent's direct operation count would prevent the `FormalCircuit` bundle from elaborating (stated at `ByteBlock.lean:16-21` and `BytesToBigInt.lean:13-17`).
14. **Hand-write `ElaboratedCircuit` when `elaborate_circuit` hits kernel recursion**; close `output_eq` by `Subsingleton.elim` when the output is `unit`.
